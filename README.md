# Wayrest

> A pedagogical Airbnb clone built to learn **Spec-Driven Development (SDD)** — where every feature is defined by a spec before being implemented by an AI coding agent.

---

## What is this project?

Wayrest is a full-stack accommodation booking platform built with Nuxt 3, TypeScript, Tailwind CSS, and Supabase. It was developed entirely without writing code manually — every component, API route, and test was generated by Claude Code from structured specs.

The project serves as a practical laboratory for mastering the SDD workflow: write a spec, submit it to an AI agent, answer its questions, validate the output, commit both the spec and the code.

## Features

- **Homepage** — listing grid with search bar (destination, dates, guests)
- **Listing detail** — photo gallery, amenities, host info, booking card
- **Booking flow** — 3-step tunnel (summary → payment → confirmation)
- **Authentication** — email/password with modal UI, session persistence (24h)
- **My Bookings** — authenticated user's booking history with status badges
- **Design system** — warm Ember/Pine/Parchment palette, Fraunces + Inter typography

## Spec-Driven Development

This project follows the SDD methodology:

```
You write the spec  →  Agent asks questions  →  You answer  →  Agent implements  →  You validate
```

Every feature in `specs/features/` follows the same structure:

| Section | Purpose |
|---------|---------|
| **Context** | What this component does and does NOT handle |
| **TypeScript Interface** | The exact contract — no ambiguity |
| **Expected Behaviors** | Numbered list — each item maps to one test |
| **Edge Cases & Errors** | What happens when things go wrong |
| **Technical Constraints** | Stack, patterns, dependencies imposed |
| **Expected Tests** | Named test cases to cover |

Undocumented decisions made by the agent are flagged inline with:
```typescript
// SPEC-GAP: decision made → reason
```

## Getting Started

### Prerequisites

- Node.js 20+
- A [Supabase](https://supabase.com) project
- WSL2 (if on Windows)

### Installation

```bash
git clone git@github.com:ptiswitz/wayrest.git
cd wayrest
npm install
```

### Environment Variables

Copy `.env.example` and fill in your values:

```bash
cp .env.example .env
```

```env
# Supabase
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key

# Auth
AUTH_SECRET=your-32-char-random-string
NEXTAUTH_URL=http://localhost:3000
```

Generate `AUTH_SECRET` with:
```bash
openssl rand -base64 32
```

### Database Setup

Run these SQL statements in your Supabase SQL Editor:

```sql
-- Listings
CREATE TABLE listings (
  id bigserial PRIMARY KEY,
  title text NOT NULL,
  city text NOT NULL,
  country text NOT NULL,
  price_per_night numeric NOT NULL,
  image_url text,
  slug text NOT NULL,
  description text,
  guests integer NOT NULL DEFAULT 1,
  bedrooms integer NOT NULL DEFAULT 1,
  beds integer NOT NULL DEFAULT 1,
  bathrooms integer NOT NULL DEFAULT 1,
  amenities text[],
  host_id bigint,
  cleaning_fee numeric NOT NULL DEFAULT 45,
  service_fee_percent numeric NOT NULL DEFAULT 10
);

-- Hosts
CREATE TABLE hosts (
  id bigserial PRIMARY KEY,
  name text NOT NULL,
  avatar_url text,
  created_at timestamptz NOT NULL DEFAULT now()
);

-- Listing images
CREATE TABLE listing_images (
  id bigserial PRIMARY KEY,
  listing_id bigint REFERENCES listings(id) NOT NULL,
  url text NOT NULL,
  position integer NOT NULL DEFAULT 0
);

-- Bookings
CREATE TABLE bookings (
  id bigserial PRIMARY KEY,
  listing_id bigint REFERENCES listings(id) NOT NULL,
  user_id text,
  start_date date NOT NULL,
  end_date date NOT NULL,
  guests integer NOT NULL DEFAULT 1,
  full_name text NOT NULL,
  email text NOT NULL,
  nights integer NOT NULL,
  price_per_night numeric NOT NULL,
  cleaning_fee numeric NOT NULL,
  service_fee numeric NOT NULL,
  total numeric NOT NULL,
  reference text GENERATED ALWAYS AS ('WR-' || LPAD(id::text, 8, '0')) STORED,
  created_at timestamptz NOT NULL DEFAULT now()
);

-- Users
CREATE TABLE users (
  id text PRIMARY KEY,
  full_name text,
  email text UNIQUE NOT NULL,
  password_hash text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

## AI Tooling

### Claude Code
All implementation was generated by [Claude Code](https://code.claude.com) from specs in `specs/features/`. The agent reads the spec, lists its questions, and implements only after receiving answers.

### Graphify
[Graphify](https://github.com/safishamsi/graphify) builds a knowledge graph of the codebase that Claude Code queries instead of reading raw files.

**Result: 14.9× token reduction** — 432 tokens vs 5,133 tokens per query.

```bash
# Rebuild the graph after significant changes
/graphify .
```
